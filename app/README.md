# CS412 Android App

## Assignment 2

This app demonstrates the use of multiple Android activities, explicit intents, and implicit intents.

### Features

- Main Activity displays my full name and student ID
- Explicit intent launches the Second Activity
- Implicit intent launches the Second Activity
- Second Activity displays five mobile software engineering challenges
- Main Activity button returns to the Main Activity
